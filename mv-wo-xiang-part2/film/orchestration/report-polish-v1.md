## 2. 做法

### 2.1 底层统一走 `life.js`

呼吸、眨眼、短臂摆动、视线延迟全部改成 `life.js` 的 `breath / blink / sway / gaze`；
群像里每只螃蟹传不同 `seed`，自动错开呼吸与眨眼相位。

### 2.2 `polish-v1.js` 只补“表演曲线”

| 函数 | 作用 |
| --- | --- |
| `gesture(t, start, dur, o)` | 反向预备 0.12 → 快速到位 → 过冲 5% → 回落安定；所有抬手/推/按都用它 |
| `release(t, ...)` | `gesture` 的反向，用于“放下、收回” |
| `bounce(t, at)` | 落地后的重心回弹 |
| `gaze(t, from, to, at, dur)` | 眼睛先动、带延迟与过冲（内部走 `life.gaze`） |
| `face(t, events, seed, o)` | 表情状态机：按时间切眼型/嘴/眉；跨眼型切换用 1.5 帧眨眼遮住，同族眼型（竖条↔竖条）直接换；`snap:true` 用于闪光/睁眼这类该“弹开”的瞬间；`noBlinkIn` 用来保护台词首帧与情绪最高点 |
| `walkCycle` / `weightShift` | 走路四脚与站立重心 |
| `passerby` | 路人独立步频/相位/方向 |

新表情按语义使用：`shock`（闪光、被挤、惊醒）、`squint`（盯着看/倔）、`side`（侧目看手机）、`teary`（骨子里那句的克制）、`dazed`（走神）、`smirk`（台上表演）、`pout`（不服）、`angry`（健身最后那段）。

## 5. 说明与已知限制

1. **字幕遮挡**：字幕框在 y≈898–990。v1-06 的顾客上移 80 px、v1-14 的主角上移到 y=900，都是为了让“扫码的手/手机”和“吃药的手/嘴”落在字幕上方；v1-08/v1-16 的角色下半身仍会被字幕压住，但表情与手都在上方。
2. **v1-05 的构图限制**：原场景把相机放在抽屉左侧（x 430），角色从右侧画外伸手，短臂长度决定手够不到相机。这一镜保留“画外手臂”的处理，用抬手→下压→松手、落灰和震动线来表达“把相机放下”，没有拉长肢体或改比例。
3. **转场叠化来自管线**：`src/transitions.js` 会给带“→”的转场做 0.18 s 叠化（v1-05、v1-09、v1-14 等）。本报告中的“硬切/承接”描述的是镜头内部表演；画面上看到的短暂双影属于既有转场系统。
4. **眼型切换**：跨眼型（竖条↔圆眼）用 1.5 帧眨眼遮住，所以抽到的静帧偶尔会看到闭眼，那正是过渡帧；闪光/睁眼用 `snap:true` 直接弹开。
5. **v1-09 的表演尺度**：舞台景别大，角色只占画面很小一块。已把 u 从 19→14 改为 22→16；如果仍觉得“笑收掉”读不到，可以再放大 2–3 u（只改一个常量）。
6. 群像（v1-01 剪影、v1-03 旅客、v1-13 人群）都加了独立眨眼；v1-06 背对的店员与 v1-12 背对的门边乘客没有脸，因此没有眨眼。
