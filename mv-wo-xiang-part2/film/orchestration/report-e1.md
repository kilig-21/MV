# E1 · intro + verse1 + 两个 hook 的表情灵动化

日期：2026-11-01 · 范围：`i-01`~`i-05`、`v1-01`~`v1-18`、`h1-01`、`h2-01`（25 镜）
状态：完成，`cut --from 20.97 --to 59.44 --name e1` 已通过

## 一句话

把这一段里 **112 处一帧硬切的表情** 收成 **68 处**（其中 21 镜有主角），每一处都改成 3–5 帧的
渐变 + 「眼睛先到、嘴晚一帧」+ 换挡前一次极轻的眉动；视线从匀速平移改成「停半拍—跳一下」。
只动表情与视线，时间码、构图、角色比例没碰。

## 1. 新文件 `film/src/expr-e1.js`

三个函数，全部建立在 life.js 的 `expr()/browLift()/eyeDart()/blink()` 之上，不改共享模块：

| 函数 | 作用 |
|---|---|
| `faceE1(t, keys, o)` | 带过渡的表情，直接展开进 `clawd()`：`{ eyes, mouth, brow, browDy, blush, sweat, blinking }` |
| `dart(t, keys, o)` | 视线跳看，默认 `dur 0.09` / `overshoot 0.12` |
| `dartTrack(t, fn, o)` | 把一条连续的视线函数采样成「每 0.32 s 看一眼」的跳看（h2-01 追灯箱用） |

`faceE1` 在 `expr()` 之上多做了四件事：

1. **嘴比眼晚 `mouthLag`（默认 0.045 s ≈ 1 帧）**：眼睛先到位，嘴再跟上，
   换脸看起来是「愣一下—再变」，不是整张脸同时刷过去。
2. **眉毛和眼同步到**，而且每次换挡前 `liftPre`（默认 0.14 s ≈ 3 帧）用 `browLift()` 抬一下；
   `brow` 是 `null` 时看不出来，有眉型的镜头（`worried`/`angry`/`up`）才看得见这个预告。
3. **支持逐关键帧 `ramp`**：`{ at: 1.34, eyes: 'wide', ramp: 0.09 }` 只影响那一段过渡，
   闪光灯、打滑这种该快的拍可以给 0.09，情绪转折给 0.20–0.24。
4. **眨眼只落在静止段**：换挡窗口 ±0.14 s 内一律不眨，`noBlinkIn` 区间照旧生效。
   返回 `blinking`，镜头把它接到 `look = f.blinking ? 0 : …`。

关键帧语义沿用 `expr()` 的 end-at-key：`at` 直接写歌词/动作的重音时刻，不用自己往前挪。

## 3. 验收

### 3.1 六帧连续抽帧

每一处表情变化前后各抽 3 帧（间隔 0.1 s，共 6 帧），裁到脸部放大 16 倍拼条：

```
film/out/e1/<镜>-<a|b|c>.jpg   共 36 条，全部 Read 过
```

拼条工具：`film/out/_e1-strip.py`（只做裁剪拼接，不参与成片）。

看过的结论：

- 每一次换挡都是 3–5 帧的过程，**没有一帧跳变**；
- 跨眼型（`normal/look` ↔ `wide/shock/dazed`）的过渡里，恰有 **1 帧** 是两种眼型各半透明的
  「灰盘」，与 `report-expr-blend.md` 第 2 节实测一致。这类过渡我一律用 `ramp 0.10–0.14`，
  把灰帧压到 1 帧（41 ms）；
- 嘴比眼晚一帧在拼条上看得出来：眼已经换了，嘴还停在上一格；
- 有眉型的镜头能看见换挡前 2–3 帧的那次抬眉（v1-04 2.15 / v1-14 0.15 最明显）。

### 3.2 整段冒烟

```
node build.mjs cut --from 20.97 --to 59.44 --name e1
```

`film/out/contact-e1.jpg`）整张 Read 过：18 个镜头之间的切换都正常，没有残留的报错帧。

## 4. 已知限制

1. **v1-05 的脸在画外**。这一镜 `cx = 2070`、`u = 36`，角色身体右半边在 1920 之外，
   眼睛落在 x≈1962，根本不在画面里。表情代码我照规矩改成了渐变（0.56 / 1.24 两处），
   但这一镜实际看到的是伸进抽屉的手臂 + 抽屉本身，**不构成可验收的表情变化**。
   要让这镜有表情，得先改构图（把 cx 收到 1750 左右），那是构图活，不在这一轮授权范围内。
2. **跨眼型过渡的那 1 帧发灰**：机制层面的已知特性，不是这次新引入的。所有这类过渡
   都压在 1 帧（ramp 0.10–0.14 或 smoothstep 两端停留），成片尺度上读作快速过渡。
3. **i-01 ~ i-04 没有角色**（夜城 / 街角 / 站台 / 空车厢），这一轮没有表情可动，
   文件一个字没改。
4. **路人**（v1-03 的旅客、v1-13 的 8 个乘客）从三元硬切换成了 `faceE1` 的短过渡，
   但他们的脸只有 3–6 px，读不出细节——改是为了整段扫过去不出现「一帧闪」，
   不是为了看他们的表情。
5. 没有动 `src/character.js`、`src/life.js`、`src/main.js`、`src/transitions.js`、
   `build.mjs`、`data/shots-extra/*`，也没有动别人的镜头文件。
