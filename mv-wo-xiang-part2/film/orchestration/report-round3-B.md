## 零、先解决共性病根：角色在看镜头，不在看他正在做的事

`clawd()` 的 `look` 只能把眼位左右平移，画不出「抬眼 / 垂眼」，所以前几轮所有"给视线落点"的修改最后都只剩一个横向偏移。
`fix-round3b.eyesAt()` 在 `character.js` **同一套 rig 坐标**上（眼心 x=±3u、y=−6u，嘴 y=−3.8u）补了一层可控视线的眼睛：

- `yaw` 让眼位与瞳孔一起偏（0.13u / 0.26u），`pitch` 让眼位与瞳孔上下偏（0.07u / 0.30u）——只动瞳孔会读成"眼睛没转"；
- `lid` 用身体色压住眼白上半、再压一条墨线，做出「半睁 / 垂眼」；
- 眼白、瞳孔、高光的尺寸与 `character.js` 的 `dazed / side` 完全一致，不引入新画法。

本轮的七个镜头全部改用它（`clawd(..., eyes:'none')` + `eyesAt(...)`），所以每处都能做到**眼睛先到、身体再到**。

## 一、逐镜改了什么

### 1. v2-03 云遮路灯（85.93–88.08）

- **云**：原先是三块灰色椭圆硬边落在一起（读成飞碟）。改成**两条横向云带**，每条由 8 个互相重叠的扁椭圆组成（本片云的语言就是 `scenes-chorus23.cloudBank` 那一套），下暗上亮两层 + 断断续续的顶缘受光弧，剪影天然是绒边。
- **路灯**：灯头（原来那个暖色圆）下面接上灯杆、灯罩、灯座和两圈铁箍，光从灯头**往上**铺两道很淡的扇形 —— "他想看见的太阳"其实是这盏灯，和镜头说明里的「暖色的路灯」对上了。
- **主角**：抬到 y=931（画面 0.86 的地面线），屋顶边线跟着抬，不再贴着画框底。
- **表演**：0.78 s 云压下来**先垂眼**（眼睑压下 0.34）→ 0.92 s 身体才沉（0.24u）→ 1.72 s 云开**先抬眼**（pitch 回到 −0.25）→ 1.88 s 才挺身、抬臂。

### 2. v2-07 满街忙人仰头（95.93–98.67）

三条反应链，绝不齐：

| 组 | 人数 | 抬头时刻 | 备注 |
| --- | --- | --- | --- |
| 左（x 104/330/556） | 3 | 0.28 / 0.40 / 0.52 | 每只错开 0.12 s；556 那只先打哈欠再抬头 |
| 中（x 764/950/1132/1306） | 4 | 0.68 / 0.80 / 0.92 / 1.04 | 整组晚 0.40 s；950 那只 1.48 s 侧身躲开落下的传单 |
| 右（x 1552/1752） | 2 | 永不 | 全程低头看手机，拇指在屏幕上动 |

- **伸手没接住 → 肩膀垮下来**：左 330 与中 1132 两只分别在 1.52 s / 1.66 s 把两只短臂举到 −1.75u，0.42 s 后（传单已经飘过去）手落回 +0.55u、身体下沉 0.34u、眼睑压下、嘴从 o 变平 —— 这是两次可读的回落。
- 抬头的幅度：眼位与瞳孔同时上移（pitch 0.15 → −0.80）、身体起 0.30u、短臂前伸、部分张嘴，且每只的 yaw / rot / 个头（13.4–16.4u）都不同。
- 眨眼仍走 `life.blink`，各自相位不同。

### 3. v2-09 旧木盒（100.86–103.86）

原状与 v2-10 是同一张桌子、同一盏灯、角色都在右侧（相关 0.64）。

- **换轴**：机位挪到盒子的右前方、略微俯视；**灯不在画里**（光从右上斜进来，桌面有光池、盒子有投影）。盒子放大到 930×330 占满画面中部，他移到**左画框**——和 v2-10 已经完全不是一个轴。
- **盒盖**：原来是绕左上角旋转的一块木板（掀开时像空中悬着一块板）。改成**绕后缘的透视压扁板**：掀开时是后缘上一条 104 px 高、两端内收 74 px 的板，合上时铺满盒面，落定时还有一次阻尼回弹。
- **表演**：视线先落在信上（yaw 0.72 / pitch 0.55），跟着按下去；合盖后还看着盒子，2.40 s 才垂下眼睛（眼睑 0.52 + worried 眉 + 平嘴），手停在盖上按两下再收回。
- 加了 5% 缓推，整镜不会是一张死图。

### 4. v2-10 写词的书桌（103.86–106.33）

原状：头是正的、眼睛平视镜头、笔和短臂没有连接（笔是道具自己动）。

- **换轴**：机位到桌子**左后方、低机位**——桌面远边斜着走、台灯只露半截在**左画框**、桌上补了冷掉的杯子 / 两团废纸 / 墙上三页贴着的词稿，纸堆压在左前景。
- **笔**：`penTo(hand, tip)` 从手心画到笔尖，握点在笔杆靠近尾端；笔尖就是落笔点。
- **字**：每行 4 个"字"，每个字由 2–3 条短笔画搭起来，笔尖走到哪个字就长到哪个字，写完一个留一个——所以纸上的字和笔尖是**同一个点**，不存在"道具自己在动"。
- **表演**：整镜埋头（pitch +1.0、眼睑 0.32、身体下沉 0.20u、身体前倾 −0.20 rad 并在写字时继续往纸里压）；手腕 0.12 s 一次高频抖；0.96 s / 1.66 s 两次抬头看灯再低头（眼睛先到、身体 0.10 s 后到）。

### 5. v2-16 递耳机（114.12–116.40）

构图按 B 评审的建议保留（这是"递"的交代镜，改的是 v2-17），只补视线与幅度：

- 父亲：看同事（yaw 0.80）→ 抬手时视线跟着耳机往下 → 戴好后回来看同事；抬手幅度加到 1.9u。
- 同事：**接的时候愣一帧**（squash 放大 0.16）→ 看耳机（yaw −0.72 → −0.30、pitch 0.55）→ 闭眼听（`smile` 眼型）。
- 加 4.5% 缓推。

### 6. v2-17 自豪他儿子（116.40–118.99）

原状：与 v2-16 同机位同站位（相关 0.947），两人是同一张闭眼笑脸，谁也不看海报，全片非字幕镜头里平均帧差最低（0.34）。

- **换轴 30°**：站到屋子右侧墙角斜看过去。海报变成画面主体（646×616，占画宽约 1/3；米色卡纸衬边 + 标题条 + 微倾，一眼是"印出来的海报"而不是窗户）；左墙补两张家常照片。父亲 (u=31) 与同事 (u=26) **错开半个身位、一大一小**。
- **表演节拍**：0.10 s 下巴先低（预备）→ 0.26 s **眼睛先转**（yaw 0.15→0.86、pitch 0.30→−0.92、睁眼、眉上抬）→ 0.36 s 身体才转 → 0.66 s 张嘴说（说 0.86 秒后收回）→ **1.00 s / 1.28 s 拍同事肩膀两下**（间隔 0.28 s，手臂摆幅 1.45u）→ 1.14 s 同事睁眼 → 1.24 s 跟着抬头看海报（yaw 0.74、pitch −0.86、o 嘴）→ 1.72 s 父亲得意地眯一点。
- **两人眼型分得开**：父亲是圆眼 + 上挑眉 + 微笑；同事是放大的圆眼 + o 嘴（惊讶）。
- 加 5.5% 缓推（朝海报）。

### 7. o-03 站台长椅（226.00–236.00）

原状：10 秒里他始终正对镜头，列车开走也没有目送。

- **目送**：0.50 s 眼睛先转 → 0.62 s 身体转到 0.30 rad（约 17°）、重心右移 10 px，视线跟着车尾缩进隧道。
- **落到报纸**：4.30 s 车尾进洞，眼睛先落（pitch → +0.85、yaw 收 0.42），身体晚 0.2 s 才回来；视线跟着地上那张被风推着走的报纸往右。
- **回到正前**：7.20–8.30 s 慢慢转回中央，眼睑压下来一点。
- **呼吸**：6.55 s 起一次 0.9 s 的深呼吸（身体 ±0.11u），呼吸时眼睛不眨。
- 推近、闪灯、风、站台渐暗全部保留。

## 三、已知限制

1. **v2-07 是远景**，九只螃蟹的表情只能靠眼位、俯仰和姿态读，没有做逐只口型；伸手那两下的"没接住"要靠连看才成立（静帧只有收手后的垮肩）。
2. **v2-10 的笔会随笔尖到手的距离改变长度**（34–100 px）。这是为了"笔必须接在手上"付的代价：短臂只有一段，画不出肘与腕，笔不伸缩就只能脱手。
3. **v2-17 的海报由本镜自己画**（`poster()` 写在 `v2-17.js` 里），没有动共享的 `src/scenes-fix.sonPoster`，免得改到 v2-16。
4. **o-03 仍是慢镜**（10 秒平均帧差 0.76）。按尾奏的呼吸保留，不再硬加动作；评审的 B 表也把 o-02/03/04 列为"不需要硬加动作"。
5. 本轮所有新增绘制都在 `fix-round3b.js` 与这七个镜头文件里；`paper()` 纸感、字幕、调色板、时间码均未改。
