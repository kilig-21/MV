# 汇报 · P5 打磨：intro / hook / outro 十三镜

日期：2026-10-31 ｜ 范围：`i-01`–`i-05`、`h1-01`、`h2-01`、`o-01`–`o-06`（0–20.97、59.44–62.39、121.50–124.36、208.24–281.551771）
基准：`POLISH-DOCTRINE.md`、`STYLE_LOCK.md`、`lyric-analysis.md`、`report-intro-hooks.md`、`report-outro.md`

## 0. 一句话

这一段原来"有变化但很规律"，像程序生成的循环。现在把**节拍**改成有簇、有空档、有长有短的分布：
窗灯按四簇亮度不等地亮/灭、个别窗亮一下就灭；车灯会扫墙、车头灯最后一刻窜一下；报纸是被一阵一阵的风吹走、翻页是碎的；
招牌六块各走各的节拍；灯箱掠过有快有慢。**尾奏末帧与 i-01 首帧仍然逐像素一致（mean = 0, max = 0）。**

## 1. 统一窗灯：i-01 与 o-06 同一份实现

新增 `film/src/polish-intro-outro.js` 的 `cityWindowsIO()`，`scenes-intro.cityWindowsLit()` 与
`scenes-outro.cityWindows()` 都只是转调它。这样：

- 楼群、窗位、起亮阈值、熄灭顺序全部同源，**首尾成环不是靠对参数，而是靠同一份代码**；
- i-01 传 `litP` 走"亮起"，o-06 传 `offP` 走"熄灭"，o-04/o-05 传 `litP:1`（全亮）。

每扇窗现在各自拥有（全部由种子散列决定，逐帧不沸腾）：

| 属性 | 分布 |
| --- | --- |
| 起亮时刻 `th` | 四簇：0.02–0.14 / 0.23–0.50 / 0.57–0.82 / 0.85–0.99，簇内随机 → 有连亮、有空档 |
| 亮度 `bri` | 0.52–0.96，暖/冷各四种色阶 |
| 起亮速度 `riseDur` | 多数 0.06–0.22 s（啪一下），约 28% 是 0.34–0.84 s（灯管预热） |
| 起亮抖动 | 约 30% 的窗带 0.35–0.85 强度、22–70 rad/s 的独立抖动 |
| 寿命 `life` | 约 19%（101 扇里 19 扇）是 0.4–2.0 s 的"亮一下就灭" |
| 熄灭时刻 `offAt` | 四簇：0.02–0.09 / 0.19–0.45 / 0.53–0.73 / 0.76–0.93；中右一扇压到 0.95 |
| 熄灭抖动 | 每扇 0.18–0.68 s、20–64 rad/s 的独立节奏；最后那扇 0.62 s、更慢 |

统计（`node film/tools/window-rhythm.mjs`，复刻同一段 RNG）：

```
windows 101 blip 19
起亮阈值 th     mean 0.534 sd 0.318
熄灭阈值 offAt  mean 0.523 sd 0.278
起亮直方图(0.1 桶) 12 10 8 9 10 2 13 9 7 21   ← 0.5–0.6 有一段空档，尾段成簇
熄灭直方图(0.1 桶) 14 2 10 9 5 16 14 11 16 4  ← 开头一簇、随后明显空档
```

相邻起亮间隔的阈值差 sd 0.0136（均值 0.0095），熄灭侧 0.0150（均值 0.0091），最小 0、最大 0.108 —— **不是等距**。

`introCity()` 增加了 `litSpan`（默认 4.4，与 i-01 的 `d` 一致），o-04/o-05/o-06 与 i-01 亮灯进度的手感一致。

## 2. 逐镜改动

| 镜号 | 问题 | 改法 |
| --- | --- | --- |
| i-01 | 窗灯按阈值均匀亮，像扫过 | 换成上面的统一实现：四簇起亮、亮度/预热/抖动各异、19 扇亮一下就灭；镜头与暗起不变 |
| i-02 | 只有地面一道三角形光 | 新增 `carLightOnWall()`：软椭圆光斑贴着立面从左边扫到右边（宽光斑 + 更亮的灯罩切线），地面改成同步移动的软光池；路灯原有的两下抖动保留 |
| i-03 | 车头灯匀速逼近 | 速度改成 `e^2.0×0.66 + surge^1.4×0.34`：最后 0.36 s 明显窜一下（画面里车头宽度从约 320 涨到 520）；灯管在车进站时随电压轻微抖（`near` 权重 + 偶发尖峰），全屏压亮也带一点呼吸 |
| i-04 | 风是匀速推、报纸一路平滑飞走 | 改成三阵风（1.40 / 2.22 / 2.92 s），位移是"走—停—走"的台阶；风线只在起风时出现；报纸右半页向中缝折（`flapK`，一阵风翻一下），翻页节奏是碎的 |
| i-05 | 只有眨眼 | 保留 3.27 s 那一眨（剧情点），再加一次极轻的呼吸雾气（1.62–3.42 s，径向雾 0.075 透明度，随呼吸鼓起又散掉） |
| h1-01 | 六块牌子同一节奏 | `SIGN_CFG`：0.26 / 0.96 / 1.21 / 1.60 / 1.86 / 2.14，间隔 0.70/0.25/0.39/0.26/0.28；每块起亮时长、抖动次数（1–4 次）、相位都不同；最后一块（名字的形状）通电后有 0.6 s 的电流余抖，光晕随亮度呼吸 |
| h2-01 | 灯箱等距、匀速 | 速度 `560×(1+0.42·sin(2.2t+1.2))`，瞬时 325–781 px/s（相邻 0.8 s 的平均位移 641→357→556，快慢肉眼可辨）；位置用积分出的 travel 而非匀速；间距 540–870 px 不等；拖影长度跟着即时速度变；眼睛仍用 0.1 s 滞后的灯箱位置 |
| o-01 | 环境太安静 | 远景加 12 盏零星窗灯，4.6–12.4 s 之间各自熄灭（间隔不等、灭前抖一下）；末班车改用 `u^0.86`，出站比进站略快 |
| o-02 | 三根灯管灭得太整齐 | 熄灭时刻 2.55 / 6.85 / 10.55（间隔 4.30 / 3.70），灭前各自抖 0.62 / 0.44 / 0.86 s，中间那盏"假死"一下又回一口气；座位上的报纸颤动用四组不成整数倍的正弦叠加 |
| o-03 | 只有车走 | 站台地上加一张纸：车走带起的风在 4.35–6.4 s 极轻地掀它——整张纸的倾角只在 -0.12±0.05 rad 内动，抬起的一角最多 0.22 rad，然后落回；角色加入呼吸/摆动，9.05 s 眨眼后眼睛转为 `sad` |
| o-04 | — | 通过 `introCity` 自动用上新窗灯（1.30→1.00 拉远不变） |
| o-05 | — | 同上（名单排版未动） |
| o-06 | 灯灭得太匀；最后一点光散得太顺 | 熄灭顺序换成成簇分布；最后一盏（`res.hero`）在 7.36 s 有一次"将灭未灭"的塌陷（辉光降到 10% 再回来），窗本身带 0.62 s 的熄灭抖动、中途会暗到几乎看不见；8.45 s 后仍压到 0.72 |

## 3. 生命感系统（life.js / 新表情）

按协调者的要求接入了 `src/life.js`，只用在有人物的四镜：

| 镜号 | 用法 |
| --- | --- |
| i-05 | `sway`（4.2 s 周期）+ `breath`（2.6 s、0.05u）+ `blink`（seed 45，slot 1.6 s，2.4 s 后停用）+ `gaze`（视线 0.15 s 滞后、1.0 s 缓慢转开） |
| h1-01 | `breath` + `sway` + `blink`（抬头那一刻 `enabled:false`，之后不再眨）+ `gaze`（2.02 s 起 0.12 s 滞后、0.82 方向） |
| h2-01 | `breath` + `sway` + `blink`（seed 73）；眼型改 `dazed`（夜班车的困），跟随灯箱的 look 不变 |
| o-03 | `breath` + `sway` + `blink`（seed 351，8.6 s 后停用）+ `gaze`（6.8 s 起 0.14 s 滞后、0.9 s 落到 0.10）；9.12 s 后眼型转 `sad` |

说明：i-05 的 3.27 s 与 o-03 的 9.05 s 两处眨眼是分镜写好的剧情点（前者"眨一下收尾接 v1-01"，后者"眼睛落下来"），
仍然保留为显式帧条件；**其余所有眨眼都走 `blink()`**，且情绪最高点（h1 抬头后）传 `enabled:false`。
