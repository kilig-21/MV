## 目标

把第一段主歌逐句拆成镜头表，这是全片「画面跟歌词走」的第一次完整检验。

## 覆盖歌词（以 LRC 为准）

20.97「他们说他变了」→ 59.44「他希望自己名字伴随你的每个日夜」，约 15 句。

## 每格必须写满

| 字段 | 要求 |
| --- | --- |
| 时间码 | t0 / t1，精确到 0.01 秒 |
| 景别 / 构图 | 远 / 中 / 近 / 特写；角色在画面中的位置 |
| 画面内容 | 具体到物件与可见细节 |
| 动作 / 变化 | 这格发生了什么，不允许「站着」 |
| 转场 | 硬切 / 动作接 / 声音接 / 物件接 |

## 内容要求

- 直接呈现歌词里的事：地铁、签名、酬劳、明信片、安眠药、健身、三个学英语 App、2Pac 海报。
- 允许少量不完全照字面但有余味的画面，但每句必须能对应。
- 同一背景不得连续跨三句不变化。
- 动作可从前一句铺垫，在唱到的那句落点。

## 验收标准

- 遮住歌词只看表格，能猜出大致唱的是哪句。
- 15 句全部有归属镜头，无「待定」空格。
- 用户逐条确认或修改后，本表冻结，进入动态分镜。

## 依赖

依赖「全曲时间轴」「镜头单元规范」「画风锁定」。本 issue 只做文字表，不做画面。
