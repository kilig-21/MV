# Anima · 第一束动势

15 秒，1920×1080，24 fps。瑞士动态排版；暖白、墨黑与唯一的朱红。无配音；中文字作为画面本身，不使用额外字幕条。原创程序音乐与近距离印刷音效，无外部影像。

## 三个结构与选择

1. 倒数：数字逐一被删去，归零生成标题。直接，但缺少主题变化。
2. 字母组装：五个字母轮流落位形成 Anima。易读，但像普通标志演绎。
3. 一个不愿静止的点：红色方块唤出网格，黑色模块锁定，红块逸出规则，整个网格转为字母的骨架。选择这一结构：运动本身成为故事。

## 故事

一粒红色方块从静态网格中出走，唤醒一幅会运动的排版。
起点（一个点）→ 秩序（网格与模块）→ 转折（唯一红块自由移动）→ 回响（红块成为标题旁的一枚活跃印记）。

## 参考语法

Hofmann 的黑白尺度对比与 Gerstner 的模块系统：学习留白、左对齐与规则生成。不要复制具体海报、构图、字体文件或机构标记。音乐采用原创极简电子脉冲，不引用既有旋律。

## 镜头与逐秒节奏

| 秒 | 画面 / 镜头 | 目的 / 音效 |
|---|---|---|
| 0–1 | 近景红方块落在左上网格交点；两条细线线性展开 | 立即给出主角；干燥落印 |
| 1–3 | 推入红块周围，粗模块逐拍组装；左下「从一个点」 | 让静态秩序可见；低频脉冲与印刷咔嗒 |
| 3–4 | 摄影机横向移一列，网格展开 | 音乐先进入下一段，纸张滑动 |
| 4–6 | 俯视宽景：粗黑柱形成阵列；「让秩序生长」 | 精确、无弹跳，加入钟琴式合成短音 |
| 6–7 | 短暂停顿后红块离开交点，线性走一条折线路径 | 第一次近静音；红块以正弦滑音发声 |
| 7–8 | 镜头顺红块移动，再向后拉；黑模块按距离重排 | 转折，声音延伸跨过镜头 |
| 8–9 | 画面旋转 90 度后停住，黑模块改读为抽象字形 | 第二次近静音；剪切声 |
| 9–11 | 方块和粗线重新排成五个大型网格字母 | 标志性镜头；节奏恢复，空间打开 |
| 11–15 | 暖白终幕，巨型 ANIMA、红块与「让想法，动起来。」 | 最后四秒稳定阅读，音乐收束但无片尾淡出 |

## 声画共享节拍

120 BPM，1 拍 0.5 秒，1/2 拍 0.25 秒 = 6 帧。所有落位在整拍或半拍。
画面动作使用 cubic-bezier(.7,0,.2,1)，线性用于划线与红块出走。
主脉冲从 0.5 秒开始；1.5 秒引入短音；4 秒加入闭镲；6.5–7 秒、8.5–9 秒近静音；11 秒最终落位；14 秒音乐止，尾音保留到 15 秒。
J-cut 在 3.75 秒引入后段音色；L-cut 在 7.5 秒保留红块滑音至 8 秒。

## 声音设计

| 区间 | 环境 | 动作声音 | 音乐 |
|---|---|---|---|
| 0–4 | 极轻高频机房底噪 | 印章、纸张划线、模块卡位 | 脉冲与贝斯 |
| 4–7 | 同上 | 密集干咔嗒 | 分解短音与闭镲，6.5 秒止 |
| 7–11 | 极轻底噪 | 红块滑音、剪切、模块重排 | 稀疏转密，8.5 秒止 |
| 11–15 | 近静音底 | 最终落印 | 稳定和弦，14 秒收束 |

## 排版与交付

字体统一使用本地自托管的 Noto Sans SC（OFL），含英文与中文，多个字重。12 列，96 px 边距，24 px 间距；不使用渐变、阴影、颗粒、弹跳或溶解。
文字：从一个点 / 让秩序生长 / 让想法，动起来。标题 ANIMA；小号技术字限极短标签。最后标题至少完整停留四秒。
输出 MP4、海报、接触表、源代码、重建脚本、CREDITS。无配音与对白，不生成 SRT。

## 运行说明

复用现有本地库与已安装核心依赖，避免 setup.sh 自动更新共享库。通过 PLAYWRIGHT_CHROME 指向已安装浏览器；FFmpeg 使用项目便携版。所有新文件仅写入本影片目录。
