# 评审任务 B：构图、节奏与"死代码感"（只看不改）

## 你的身份
你是这部 4 分 41 秒 MV 的**外部评审**，没有参与制作。你的任务不是夸，是找"一眼假"的地方。
成片：`mv-wo-xiang-part2/film/out/wo-xiang-part2.mp4`。

## 你要做的事
逐段看片，只评判**画面本身**：

1. 抽帧：每 3 秒一帧，用
   `./.tools/ffmpeg/bin/ffmpeg.exe -ss <起> -t <长> -i <成片> -vf "fps=1/3,scale=420:-1" .cache/reviewB/<段>/f_%03d.jpg`
2. `python tools/view-image.py <那批图> --grid 5x6 --max 1700` 拼表，Read 逐帧看。
3. 重点找：连续两帧构图雷同、大片空白、主体太小、裁切错误、角色贴边、层次扁平（前中后景缺失）。
4. 转场：抽 3 个切点前后各 6 帧，判断叠化是否太长/太短、有没有"糊一下"的感觉。

## 评判标准
- 构图：主体是否在合理位置？有没有大片无信息区域？前中后景是否有层次？
- 重复：跨镜头是否出现"同一张构图换个天色"？
- 节奏：镜头长度与歌词情绪是否匹配？该快的地方是否拖、该停的地方是否赶？
- 转场：现在的规则是叠化 0.50s / 动作接 0.22s / 节拍切 0.12s / 拉远 0.35s / 尾奏 0.70s / 动机剪辑 0.18s，硬切保持硬切。
  判断哪些边界应该是硬切却做了叠化，哪些该叠化却硬切。
- 风格：是否守住 `film/style-lock/STYLE_LOCK.md` 的扁平手绘、暖色低饱和、夜景。
