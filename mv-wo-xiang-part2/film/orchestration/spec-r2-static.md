# 第二轮补充 · 两处"近乎静止"的镜头

## 怎么发现的
用 `ffmpeg -vf freezedetect=n=0.003:d=1.2` 扫成片，全片只有这几处连续 1.2 秒以上画面几乎不变，
除尾奏（另一工人在重做）外，有两处落在正片里：

| 时间 | 镜头 | 时长 |
| --- | --- | --- |
| 46.75 起 | `v1-13`（46.56–49.16「为了成功他在八点半用安眠药来入夜」） | 1.46 s |
| 100.875 与 102.625 起 | `v2-09`（100.86–103.86「如今他看淡风月把心事埋藏在了心底」） | 1.33 s + 1.25 s |

## 要做的事
只改这两镜：让画面在任意 0.8 秒窗口里都有可见的微小变化，但**不要变热闹**——
这两处都是安静的段落，要的是"呼吸"，不是加动作。

- `v1-13`：他躺下之后，胸口起伏（bodyDy 正弦，幅度小）、眼皮在入睡前再动一次、
  床头灯的光晕有一点缓慢的明暗、背景窗外偶尔一辆车的光扫过。
  吞咽/闭眼之后不要完全定住。
- `v2-09`：合上木盒之后，手在盒盖上多停留一下再离开；盒子合上时有一次极轻的回弹；
  灯下的灰尘在光柱里飘；他的呼吸一直有。两段静止都要被"手的小动作"和"呼吸"填满。

## 约束
- 只改 `film/shots/v1-13.js`、`film/shots/v2-09.js`，可自建 `film/src/detail-r2b.js`。
- 不要改 `src/` 已有共享模块、`main.js`、`build.mjs`、其他镜头。
- 角色比例、画风、字幕位置不变。
