## 2. 为什么这次不像同一张图

旧版 o-01 / o-04 / o-05 / o-06 都画同一套城市（同 seed、同构图），只有微动。新版把“城市”拆成四种完全不同的看法：

1. **o-01 高架**：前景是桥面、桥墩、桥下湿街与电线，城市只是背景；车是主体，有方向和速度。
2. **o-05 亮窗**：从一扇窗的内部起幅，窗外是整栋楼——和 o-01 的“站在城市外面看”是相反的方向。
3. **o-06b 天际线**：只有这一镜保留 i-01 的原构图，因为它是循环的收口；前面三段已经把它“用掉”的新鲜感补回来了。
4. **o-02 / o-03 / o-04**：车厢、站台、地面三个高度，机位分别是横移、固定推近、贴地前倾，剪在一起不会混。

段落之间用 `outro.json` 的 `transition` 明确控制：o-02 / o-03 / o-05 走**硬切**（段落感），o-01 / o-04 / o-06a / o-06b 走 0.5 s **叠化**（回忆与收尾）。

## 3. 实现要点

新增 `film/src/scenes-outro-r2.js`（只新增，不改共享模块）：

- `cityHighway()`：高架、桥墩横撑、湿街、反向车流、电线、桥面余晖；`nightTrain()` 里每扇车窗向后拖 110 px 暖光，车头灯另有一束扫过楼面的光。
- `hangStraps()`：o-02 的吊环，减速时有一个 0.06 rad 的向后倾角，再慢慢摆稳。
- `blownNewspaper()`：风推报纸 = 位移（easeOut）+ 两次跳起 + 翻转 + 掀起的一角；风停后落回地面只剩很轻的颤。
- `childhoodEdge()`：一整张低机位场景。站台地面用透视线收进隧道，13 根枕木按 `q^1.55` 压缩间距，钢轨有高光；前景两张报纸 + 两只脚（`drawFoot`），隧道里车头灯随时间长大。
- `windowCity()` + `roomWindow()`：整栋楼、窗格、楼顶水箱天线；大窗里是暖房间、桌子、台灯、窗帘和 `clawd()`（U=6.2，只用官方比例）；窗棂横档/竖梃让“一扇窗”读得出来。
- `creditPanelR2()`：与字幕同一套斜切框语言，四行文案固定不变，时间轴按 13 s 重排。

镜头文件：

- `o-01.js`：1.02→1.055 推近 + 12 px 横摆。
- `o-02.js`：1.06 倍 + 横移 −46→34 px；5 根灯的熄灭/抖动参数在文件顶部常量里。
- `o-03.js`：1.03→1.09 推近；`departingTrain` 5.2 s；`breath` / `sway` / `blink` / `gaze`。
- `o-04.js`：1.00→1.05 前倾 + −10 px 下移，最后 1 s 压暗 0.18 交给 o-05。
- `o-05.js`：`z = exp(lerp(ln 5.2, 0, p))`，中心从窗 (1285,350) 移到楼 (1392,600)。
- `o-06a.js`：`introCity(scrollT 0, litP 1, zoom 1→1.025, fade 0.66)` + 新名单。
- `o-06b.js`：`introCity(scrollT 0, litP 1, offP, offSpan 7.2, zoom 1)`；hero 余晖 + `0.72 × #08101A`。

### 4.4 首尾成环（硬要求）

- **静帧（逐像素 0）**：`o-06b` t=9.551771（全局 281.551771）与 `i-01` t=0 分别渲染后：
  - JPEG 字节级一致，两组 md5 同为 `88c97acee8b0814d5bfff4bdd00a3c42`；
  - 用 ffmpeg 解成 rgb24 后逐字节比较：`mean abs diff = 0.000000`、`max = 0`、`differ_bytes = 0`（1920×1080×3 = 6,220,800 字节）。
  - 原因：o-06b 与 i-01 共用 `cityWindowsIO`，`scrollT = 0`；末帧所有窗都灭、暗场同为 `0.72 × #08101A`。
- **成片（编码误差）**：从 `outro2.mp4` 抽第 1758 帧（镜内 73.25 s）与 `out/i01v.mp4`（0–1 s 切片）第 0 帧比：
  `mean = 0.966`、`max = 60`，差 >8 的通道 17,751 / 6,220,800（0.29%）。
  这部分来自 H.264 量化与每镜各自的“镜头呼吸”偏移（`main.js` 的 CAM 漂移按 shot id 与全局时间取相位），
  与上一轮报告的成片口径一致；**渲染前的画面本身逐像素为 0**。
- o-06b 的压暗在 8.8 s 完成，而成片最后一帧在 9.49 s、静帧检查在 9.551771 s——两者都早已停稳，不存在“还差一点”的边界问题。
