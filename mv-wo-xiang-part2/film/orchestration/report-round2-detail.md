### 1. v2-15 舞台（111.85–114.12）

原状：黑洞洞的大厅 + 一束追光，观众是底部一排色块。

- **近景侧幕**：左右各加一层更暗的幕布（`#4A2922` + 4 道褶），画面有了前景框，台口不再直接贴边。
- **壹众剪影**：舞台与彩色小螃蟹之间加一排 13 个剪影（高 92–170 px 不等、各自侧头 / 倾身、部分举手机），
  再在前排加 7 个只露头顶的剪影 + 2 只举起的手机；彩色观众的 `look` 也改成各不相同（有的看向台上，有的回身和旁边说话）。
  手机是一块小亮屏 + 一点暖光，成了暗场里最下面一排小暖点。
- **返送音箱**：舞台地面左右各一台楔形 monitor（前立面散热槽、斜面喇叭网、地上拖线）。
- **地灯**：台口左右各一盏，向上打一小束很淡的光锥 + 灯罩亮斑。
- **台面反光**：追光池里 9 道横向高光（加法、α 0.05–0.12）。
- **浮尘**：62 粒只在光锥范围内可见的尘点，随呼吸缓慢摆动。

### 2. v3-10 胡同迷宫（163.15–166.41）

原状：两侧高楼夹着一条空路。

- **墙面**：左右各加排水管、雨棚、配电箱、3 扇窗（两扇没亮、一扇透出很淡的暖光）；
  4 台空调外机挂在不同高度。
- **空中**：三条下垂电线横过胡同（其中两条双线），两处晾衣绳各挂 3 件衣物，慢慢摆。
- **旧路牌**：路口左侧一根杆 + 两块带尖角的方向牌，牌面只有笔画形状（不写真实文字）。
- **远灯**：路尽头的路灯改成不规则忽明忽暗（`flicker()`），结尾仍被黑吞掉。
- **地面**：5 条透视接缝、一块井盖、3 处积水（倒着路灯与窗灯的竖光）、两处路边小垃圾。
- **挡住去路**：右侧路口堆了木箱 + 斜靠的挡板 + 塑料袋 —— 角色不是空着转身，是走到头了。

### 3. v3-11 / v3-12 城市全景（166.41–168.49）

- **薄雾**：地平线一带一层 `rgba(120,158,172,0.14)` 的横向雾带，把楼群底与街道分开。
- **鸟群**：7–8 只剪影掠过天空，翅膀一上一下（各自相位与速度不同）。
- **车灯**：街道上 16–18 对极小的车灯，暖 / 红两色、双向流动，带拖影和小光晕。
- **近景楼**：多一层更暗的剪影楼（有零星亮窗）。
  - v3-11：近景楼跑 1.7 倍横移，远景 1 倍。
  - v3-12：近景楼按 `ang × 1.62` 旋转，远景按 `ang`，旋转时两层明显分开走 —— 视差是这一镜的重点。
- **屋顶**：卫星锅、晾衣绳（3 件衣物在风里晃）、一只坐在檐口摆尾巴的猫、一根更高的天线；
  都没放在角色（v3-11 x≈1220 / v3-12 x≈960）脚下。

### 4. i-05 车窗倒影（17.08–20.97）

- **玻璃边缘**：窗内侧一圈冷色内缘线 + 上沿玻璃厚度暗边。
- **错位倒影**：倒影改成两层 —— 主体 α 0.68、往右上错开 (14, −6) 并轻微斜切；
  另有一层 α 0.07 的鬼影错开 (22, −11)。不再完全对齐。
- **压暗**：玻璃上再叠 0.11 的冷色；车厢内景（座椅、扶手）的倒影也跟着错开。
- **灯条高光**：窗外灯条在玻璃上多一层横向拉长的高光，比窗外的灯慢半拍（车速在减）。
- **眨眼保留**：3.27 s 的收尾眨眼原样保留（抽 t=3.45 确认闭眼帧）。

### 5. h1-01 招牌（59.44–62.39）

`signWall()` 的六块面板原是三条横杠（读起来像空白板）。现在在它画完之后按同一批种子把底板与面板重画，
把面板内容换成**由笔画搭起来的「名字的形状」**：

- 笔画用起笔粗、收笔细的 `brush()`（圆头），7 种结构（竖主笔 + 三横 / 包围框 / 左右结构 / 上下结构 /
  中竖带钩 / 木字旁 / 门框 / 双人旁），按种子拼成一个方块字；非主角牌下面还有一条细线 + 一行四个小笔画（小字）。
- **电流抖动**：`igniteAt()` 与 `scenes-intro.js` 的 `signSpark` 同一套起亮曲线（含镇流器抖），
  起亮期间字形再叠 ±0.9 px 的横向抖与灰度渐变，亮定后稳定。
- **六块板各不相同**：圆角半径 8 / 26 / 16 / 12 / 全圆（药丸）/ 8；板型装饰分别是遮檐条、吊链、
  双线边、四角包边（主角）、四角铆钉、顶部灯管槽；面颜色沿用原调色板。
- 主角牌的字用固定结构（门框 + 左右）而不是随机，更像一个真正的名字。
