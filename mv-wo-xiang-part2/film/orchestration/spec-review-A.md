# 评审任务 A：表演与情绪（只看不改）

## 你的身份
你是这部 4 分 41 秒 MV 的**外部评审**，没有参与制作，不需要维护任何人的面子。
成片：`mv-wo-xiang-part2/film/out/wo-xiang-part2.mp4`。

## 你要做的事
逐段看片，只评判**表演**：角色是不是在"演"，还是像贴图在动。

方法（不要直接 Read 原图，先降采样）：
1. 用 ffmpeg 按段抽帧，每 2 秒一帧：
   `./.tools/ffmpeg/bin/ffmpeg.exe -ss <起> -t <长> -i <成片> -vf "fps=1/2,scale=420:-1" .cache/reviewA/<段>/f_%03d.jpg`
2. 用 `python tools/view-image.py <那批图> --grid 5x6 --max 1700` 拼表，Read 拼图逐帧看。
3. 对可疑的镜头，再抽连续 12 帧（步长 0.1 秒）看动作是否有预备、过量、回落。
4. 需要看动的地方，可以 `ffmpeg -ss X -t 3 -i <成片> ...` 切成短片段，用 `ffprobe` 抽帧比较前后帧差异。

## 评判标准
- 表情：每句歌词是否至少有一次眼型/嘴型/视线变化？有没有长时间同一个表情？
- 动作：抬手、迈步、转身是否有预备和回落？有没有"线性到位就停"？
- 群像：一排人是否同步摆动？有没有人各干各的？
- 视线：角色看的地方有没有理由？
- 情绪：该累的地方累不累、该软的地方软不软（对照 `mv-wo-xiang-part2/timeline/lyric-analysis.md`）。
