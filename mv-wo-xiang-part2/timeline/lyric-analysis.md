# 《我想 part2》歌词分析 → 画面要求

这首歌不是"可爱小螃蟹在城里玩"。它是一首自白的说唱：**成名之后，表面的变化和骨子里的没变**。
画风是暖色扁平卡通，但内容要接住歌词里的孤独、克制和野心。可爱是表现层，不是内容层。

## 全片三个母题（每段都要能对上）

1. **名字伴随每个日夜**（hook1 59.44、hook2 121.50、v3 末句 183.83）
   → 招牌、站名灯箱、留声机、循环的唱片。这三处必须视觉同源：都是"一圈一圈亮起来/转起来"的东西。
2. **地铁 / 公交车**（"交通工具仍叫地铁" 41.39）
   → 他有钱了但还坐地铁。地铁是全片的现实锚点，也是 intro 与 v1 同一空间的原因。
3. **醒在梦境**（每次副歌收尾）
   → 副歌是"想"，不是"发生"。三个副歌逐次放大：试探 → 熟练 → 升到城市上空。
   每次收尾都要回到夜班车厢睁眼，形成三次相同的落点，才有"循环播放"的感觉。

## 分段

### intro 0–20.97（无人）
冷、慢、空。城市窗灯一盏盏亮、便利店卷帘门、空站台、空车厢、车窗倒影。
不要标题卡。这一段的功能是把观众放进"夜里的城市"，为主角出场让位。

### verse1 20.97–59.44｜他们说他变了
外层是别人眼里的成功，内层是代价。**画面上要让"外面说他好"和"他在受苦"并置**：

- 21.89 歌词不再免费 → 手机页面/价格
- 23.17 洛杉矶演出免签 → 机场、护照
- 25.80 几十万酬劳 → 合同、数字
- 31.11 路人签名 + 时尚杂志 → 被认出来，但脸是空的
- 33.76 礼物和明信片 → 堆起来的卡片，没有人
- 36.15/37.51 光鲜没埋没历练 → 亮色表面下的旧伤
- 38.76/41.39 骨子里的东西 / 仍叫地铁 → **全片最重的一句**：从豪车/红毯切到地铁，或干脆让地铁出现得理所当然
- 44.05 人来人往谁在乎他 → 人群从他身边过，没人回头
- 46.56 八点半用安眠药入夜 → 药瓶、关灯、躺下
- 49.16 健身房里付出一切 → 深夜健身房，只有他
- 51.86 三个英语软件 → 手机三个图标
- 54.34 2pac 海报 → 床沿海报，眼睛看着他
- 56.69 Black God 告诉他不能满足 → 海报/影子给出的压迫感

### hook1 59.44–62.39｜名字伴随每个日夜
招牌逐个亮，最后一块是"名字的形状"（不写真实文字）。他抬头。这是全片第一次把"名字"变成光。

### chorus1 62.39–82.63｜我想……
试探性的想象。三句"我想"要各给一个不同的物理动作，不能只是站着放光效：
呼风唤雨（抬手→云聚→雨落）、一日千里（四脚跑，城市倒退）、遨游四海（海面打开、岛升起）。
"睡在梦里"要真的躺下闭眼，"醒在梦境"要真的回到车厢睁眼。

### verse2 83.32–121.5｜梦想、谦逊、代价
- 85.93 想看见太阳却总有乌云 → 抬头看天，云挡住
- 88.08 别人要镶钻红绿灯鞋 / 90.65 他偏爱布鞋 → 两双鞋并置，他穿布鞋
- 93.50 外公说保持谦逊 → 老人形象或旧照片
- 95.93 满街忙人等馅饼 → 人群仰头等天上掉东西
- 98.67 曾渴望名利错失爱情 → 空掉的位置/合照少一个人
- 100.86 看淡风月把心事埋心底 → 埋东西的动作
- 103.86 话变少埋头苦干 → 桌前，只有笔和灯
- 106.33 即使即刻逝世也能出版四张专辑 → 四张唱片/四张纸
- 108.85 必须努力 / 109.91 朋友问何必 → 对话感，他看着朋友
- 111.85 说唱不是儿戏 → 麦克风/舞台
- 114.12 父亲递给同事耳机 → **全片情绪最高点之一**，父亲的手、耳机线
- 116.40 自豪他儿子是巨星 → 父亲的表情
- 118.99 无人问津的岁月 → 冷清的旧场子
- 121.50 名字伴随每个日夜 → hook2

### chorus2 124.36–145.40｜同样的词，第二次
动作更顺、更大：平台更大、海更宽、云床变浮岛、音符从身体里长出来（不是耳机）。
不要重复 chorus1 的构图，要明显"升级"。

### verse3 145.93–188.28｜他是谁
- 146.72 答案明了 → 分割的两半合上
- 148.12 代表智慧 → 书页自己翻
- 148.89 黎明前的鸣鸟 → 鸟掠过天线，天边一线亮
- 150.57 地下留有光辉领你寻宝 → 旧地铁图随他脚步亮起（呼应母题 2）
- 152.81 走向伟大感知讯号 → 天线信号圈
- 155.24 缺物质但不舒服但知足 → 很小的房间，他把灯调亮
- 158.17 只有家人才是神赐福的完美艺术 → **全片最暖的一镜**：三只螃蟹围桌吃饭
- 160.83 有人阻挠 → 挡在门口的影子
- 163.15 愤怒让你迷路 → 迷宫窄路，越走越偏
- 166.41/167.20 无论身在何方、世界多疯狂 → 城市铺开、缓慢旋转
- 168.49 别让俗套掩盖锋芒 → 一排一样的螃蟹里只有他是橙色
- 170.95 拿公文包挤进上班队列 → 队列走进大楼，他抬头看楼顶
- 173.44 天真随年龄退却 → 粉笔画被雨冲淡
- 176.13 欲望无法拒绝 → 橱窗里的戒指，手停在玻璃前
- 180.81 不要与恶魔交换对戒 → 两影合一又散开
- 182.24 失意时留声机还有音乐 → 唱针落下
- 183.83 循环播放伴随每个日夜 → 唱片转，声波越过窗户，城市跟着亮（收束全片母题 1）

### chorus3 188.28–208.24｜第三次
最亮最远。梦境升到城市上空，海与城叠在一起，纸舟变唱片封套折的大船。
结尾回到车厢睁眼，与 v1 的夜街闭环。

### outro 208.24–281.55（73 秒器乐）
片尾。不要再用"我想"的想象力，回到安静的夜：城市远景、地铁驶过、车厢空掉、灯一盏盏灭，
最后回到 intro 的第一个镜头（窗灯亮起的城市），字幕与制作名单在这一段。
这样全片首尾相接，正好对上"循环播放"。

## 常见错误（要避免）

- 把副歌当"他实现了愿望"来画 —— 副歌是想，不是现实。
- 只放光效不做动作 —— 每句歌词必须有可见的变化。
- 把可爱当目的 —— 可爱是外壳，画面里要有"他没变"的那部分。
- 三个副歌画成同一套 —— 必须逐次放大。
