# STYLE LOCK · 《我想 part2》2D 动画 MV

锁定日期：2026-10-31 ｜ 对应 issue：CODI-139（S1）

画风目标来自 `style-reference/` 三张参考图：**2D 扁平手绘卡通、粗黑描边、暖色低饱和、简单几何舞台、角色有表情、多角色换色、轻微纸感**。
本文件是绘制规格的正本；镜头里不得出现与本文件冲突的临时画法。

## 3. 线条

- 角色描边宽度 = `0.30 ×` 每 rig 单位的像素（例：u=26 时约 7.8 px），描在轮廓外侧。
- 场景描边 4–6 px；字幕框 2.2 px。
- 所有描边用 `lineJoin=round`、`lineCap=round`。
- 手绘抖动：每个物件固定种子，振幅 1–2 px；**逐帧不沸腾**（同一物件每帧抖动一致）。

## 4. 形状

- 圆角矩形是唯一基础形状；圆角半径 = 短边的 12–20%。
- 角色身体圆角 1.9 rig 单位，短臂 0.62，四脚 0.5。
- 块面平涂，不做渐变脏污；光影只用「加法叠色」（`globalCompositeOperation='lighter'`）与低透明度光斑。
- 不使用 3D 光影、不描内轮廓线（角色是单一外形轮廓）。

## 5. 纸感

- 1920×1080 一次性噪声层，α ≤ 16，`globalAlpha 0.85` 叠加。
- 极轻暗角：径向 0 → `rgba(8,10,14,0.30)`。
- 颗粒只做「纸」，不做「脏」：不叠划痕、不叠污渍。

## 6. 角色

唯一源：`character-lock/official/rig.json`（官方 15×16 base）。

| 部件 | rig 坐标 |
| --- | --- |
| 身体 | x2, y6, 11×7 |
| 短臂 | x0 y9 2×2 ／ x13 y9 2×2 |
| 四脚 | x3 / 5 / 9 / 11，y13，1×2 |
| 眼睛 | x4 / x10，y8，1×2 |

- 轮廓校验：`film/character-lock/parity-report.json`，IoU 0.9636，宽高比偏差 0.0000。
  IoU 未到 1.0 的唯一原因是**官方是方角、本片按参考图做圆角**，四角面积约占 3.6%。
- 表情：点眼 / 竖眼（默认）/ 圆眼 / 笑眼 / 爱心眼 / 睡觉闭眼 / 惊讶 / 疲惫 / 难过 / 发光；嘴：无 / 微笑 / 张嘴 / o / 波浪 / 平；腮红、眉毛、汗滴、Z。
- 多角色 = 只换身体色 + 小配饰，形状与比例完全一致。

## 7. 字幕

- 位置：画面下方居中，框中心 y=944，框高 92，斜切 26 px。
- 样式：深色平行四边形底 `rgba(30,36,48,0.94)`、细米色边 `rgba(232,210,162,0.82)` 2.2 px、暖米黄字 `#F1D9A8`。
- 字体：Noto Sans SC 500，46 px；单行，超长按 1560 px 上限压缩。
- 时间：严格取 `timeline/timeline.json` 的 t0/t1；不提前、不滞后。

## 9. 禁止

- 3D、写实、厚涂、复杂光影。
- 改角色比例、加肘膝手掌、拉长肢体、换骨架。
- 每镜自带一套描边/色板。
- 用滤镜做整体调色来代替原本的配色。
- 高饱和霓虹色、纯黑大块背景（除舞台暗部）、纯白大块。
