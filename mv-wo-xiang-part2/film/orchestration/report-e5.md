# 第四轮 E5：c3-01～08 + o-03 表情灵动化

日期：2026-11-01 · 状态：完成 · 交付物：9 个镜头文件（本次实际改 7 个）+ `src/expr-e5.js`

## 一句话

c3 全段的离散表情切换（`state()` / `条件 ? 'wide' : 'normal'` / if-else 链）全部换成
`expr()` 关键帧过渡（ramp 0.15–0.20），视线换成 `eyeDart()` 跳看；o-03 保留第三轮那套
带俯仰的 `eyesAt()` 眼睛（要用它才看得见"地上的报纸"），但视线时间轴改成两次跳看 + 0.1 秒的"先眼后头"。
没有出现"用力表演"的表情：c3 每一镜 2–4 次变化，o-03 两次。

## 1. 新增 `src/expr-e5.js`

只补 `expr()` 之外的两件小事（不改 `life.js` / `character.js`）：

| 导出 | 作用 |
|---|---|
| `RAMP = 0.18` | c3 默认过渡（≈4.3 帧 @24fps，在 E5 规定的 0.14–0.22 中间） |
| `eyeName(eyes)` | 混合值 `{a,b,p}` 当前读作哪一种眼型（取 p 过半的一侧） |
| `blinkOn(e, t, o)` | 在 `expr()` 结果上叠一次眨眼：**只换 eyes**，mouth/brow 的过渡原样保留。眨眼本身仍走字符串快速路径（2 帧），不包进 expr |
| `lag(keys, dt)` | 关键帧整体后移，给"同一套视线给眼睛用一次、给头晚 0.1 秒再用一次" |

`blinkOn` 解决了一个实际问题：以前 `if (blink(...)) eyes = 'closed'` 会连带丢掉 expr 算出的
mouth/brow 过渡；现在只改 eyes 这一层。

### o-03 为什么没用 `expr()`

这一镜的眼睛不是 `clawd()` 画的，是第三轮定的 `eyesAt()`（`fix-round3b.js`）——因为
`clawd()` 的 `look` 只能左右平移，画不出"垂眼看地上的报纸"。`eyesAt` 的默认画法与
`character.js` 的 `dazed` / `side` 是同一套尺寸（0.58u × 0.72u 眼白 + 0.25u 瞳孔），
所以用它的 `yaw` / `pitch` / `lid` 表达 `dazed`（pitch −0.55 + lid 0.34 ≈ 瞳孔上翻半垂）
和 `side`（yaw 0.95）即可，不需要也不应该把整双眼睛换成 `clawd` 那套。
`expr()` 在这里没有可接的字段（eyes 固定 `'none'`），硬套会把俯仰视线丢掉。

### 3.2 过渡质量

- 中段（p≈0.5）确实会有 1 帧"两份形状叠在一起"：`sparkle→happy`（大四角星叠笑眼）、
  `tired↔normal`（短条叠长条）各 1 帧，42ms。`smooth` 缓动把 p 在中段停留压到最短，
  没有按老方案的 `p<0.5 只画 a` 退化——那会退回硬切。
- 没有把 `ramp` 压到 0.14 以下：0.15 已经约 3.6 帧，再短就看得见"跳"。
