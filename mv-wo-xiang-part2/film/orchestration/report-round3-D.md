## 1. v3-01 `他到底属于哪？`（145.93–146.72）

**问题（评审 B）**：全片信息量最大的一镜只有 0.79 s，146.72 一切分割线就没了；左右两半明度差不够。

**改法**
- **拉大明度差**：左半压一层 `rgba(4,10,18,0.44)` 冷暗；右半加 `rgba(246,201,126,0.18)` 暖洗。
- **右半加侧光**：从右画框外（1908, 196→392）斜打进舞台地面的光束 + 灯口本身的亮点，光束左缘收在地面 x≈1058–1204。
- **分割线延续到 v3-02**：v3-01 的 draw 在 `t > 镜长` 时继续画「合拢」——
  `close = smooth((t-d)/0.5)`：缝里透出的光从 8px 展宽到 ~30px 并变淡（`splitWorld` 自带的那条 6px 亮线不能删，所以用「光把它吃掉」的方式收），
  同时一道暖光从缝里向两侧铺开、并越过缝压到左边那条街上，两半的明度差在 0.5 s 里收敛 —— 读起来是「两半世界合拢」。
- **数据改动（协调者已批准，见下）**：`film/data/shots-extra/verse3a.json` 里 v3-01 的 `transition` 由
  `分割线的光 → 合一成一条夜街` 改为 `分割线的光 → 叠化合一`。`transitions.js` 认到「叠化」→ 0.50 s 叠化，
  于是 146.72–147.22 之间 v3-01 仍以 alpha 递减被画在下面，合拢动画这时才看得见。
  （转场按**上一镜**字段生效，v3-01 的字段正好作用在 v3-01→v3-02 的边界。）

**证据**：`film/out/stills-v3-01/t_0|0.26|0.52|0.75.jpg`；成片抽帧见下方「转场验收」。

## 2. v3-08 `只有家人才是神赐福的完美艺术`（158.17–160.83）

**问题（评审 A）**：三个人同一张闭眼笑，2.66 s 没有一次睁眼、没有对视；菜夹到了妹妹碗里；Clawd 只是旁观者。

**改法（一条完整动作链）**
- **外公（绿）**：0.28 s 先下压一帧做预备 → 0.38 s 抬起（armL 从 0 到 −1.02u）→ 0.60 s 端菜 → 1.30 s 放下，最后手臂停在桌面（+0.10u 的静止位）。
  **筷子从外公的手（1022, handY(armA)）出发，一直连到菜上**，道具不再自己飞。
- **菜**：一条抛物线，从外公的碗 (1108, 664) 越过汤锅，落进 **Clawd 的碗 (800, 686)**；落点后碗里多一撮菜并冒一口热气。
  不再有横跨整桌的第二次飞行（旧版那条才是「夹到妹妹碗里」的观感来源）。
- **Clawd（橙）**：0.86 闭眼一下 → 0.94 睁眼（`eyes:'normal'`）→ 视线 look 0.95、brow up、嘴变 `o`（惊讶）→ 1.46 收起 → 1.52 点头（bodyDy +0.42u、rot +0.04，带缓出）→ 1.72 起回位 → 之后回到 `happy` + `smile`。
- **妹妹（粉）**：全程 `happy` 闭眼笑，嘴里在嚼（9 Hz 的小起伏），1.02–1.76 侧头看夹菜；嘴型 `smile`。
- **眼型/嘴型分开**：外公端菜时 `normal`（睁眼盯碗）→ 放下后 `happy` + `grin`；Clawd `normal`→`happy`，嘴 `o`→`smile`；妹妹 `happy` + `smile`。三张脸不再同一张。

**证据**：`film/out/stills-v3-08/t_0.35|1.15|1.70|2.50.jpg`（0.35 预备、1.15 睁眼对视、1.70 点头、2.50 回到闭眼笑）。

## 4. v3-13 `也别让俗套生活掩盖你的锋芒`（168.49–170.95）

**问题（评审 A）**：「只有他是橙色」成立，但「身上亮着光」不成立；整排灰螃蟹步态同步、个头一致。

**改法**
- **相位**：每只灰螃蟹比前一只晚 **0.08 s**（`phOff = i·0.08·cad`，换成弧度扣在相位上），起步相位另有一份随机，不再同帧迈同一条腿。
- **个头**：以 22.8 为基准 **±4%**（`u = 22.8·(1+((i%5)-2)·0.02)`），橙色那只 25.2。
- **步态幅度**：腿 0.25→**0.32**，上下起伏 2.2→2.6+0.04u（24 fps 下看得见抬腿）。
- **橙色那只**：走两步（t≈0.82 s）后**轮廓光提亮一档**——先用 u×1.026 的暖色无描边剪影垫底再画本人，边缘亮一圈；
  同时**眼睛加高光**（两颗 0.17u 的奶白点）、brow up、嘴从 `flat` 转 `smile`。0.82 s 前后有清楚的「不发光 → 发光」对比。

**证据**：`film/out/stills-v3-13/t_0|0.8|1.6|2.4.jpg`（0 无光 / 2.4 有轮廓光与眼中高光）。
