# 约十秒副歌样片

当前只制作用户授权的副歌试片，采用已选择的 A 纯 2D 像素，歌词完整显示，只有歌曲原声。
成片：wo-xiang-chorus-preview.mp4；字幕：wo-xiang-chorus-preview.srt。
原声片段 62.35–72.766667 秒，10.416667 秒、24 fps、250 帧、1920×1080。
故事构想和已讨论边界见 TREATMENT.md 与上级 BRIEF.md。

复现：在 Anima 根目录执行 `node mv-wo-xiang-part2/chorus-preview/build.mjs`。
关键帧：追加 `--stills`。也可运行本目录 build.ps1 / build.sh。
原音频依赖上级 assets/source-audio.flac；本机共享库 C:/Users/Lenovo/lemo-opuscar，支持 LEMO_OPUSCAR_HOME 覆盖。
