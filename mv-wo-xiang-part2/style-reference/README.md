## 要学的画风

- **2D 扁平手绘卡通**，不是 3D，也不是严格像素风。
- **粗黑/深色描边**，圆角，线条略有手绘抖动。
- **低饱和暖色**：米色墙、青蓝窗/座椅、灰粉地面、芥末黄、灰绿、灰粉、淡紫。
- **简单几何舞台**：车厢、长椅、窗、门、灯、城市剪影、海和沙，块面清楚，不堆细节。
- **小螃蟹有表情**：点眼/竖眼、爱心眼、笑嘴、腮红、睡觉的 Z、惊讶的圆眼。表情是重点，不要面瘫。
- **多角色 = 同一身体换颜色**：绿色、黄色、粉色、淡紫，形状和比例完全一致，只换身体色，可加不同小配饰。
- **字幕**：暗蓝/近黑的斜切底框，细米色边，米黄或暖白字，居中在画面下方。
- **轻微颗粒/纸感**：可以有很轻的噪点或纸纹，但不要脏。

## 要保留的角色骨架

身体比例仍以官方 Clawd on Desk 的 15×16 base 为准：

- 宽扁圆角矩形身体
- 两只眼睛（可换成爱心/笑眼/圆点）
- 两侧单段短臂
- 四只短脚
- 不加肘、膝、手掌、鞋，不拉长四肢

在这个骨架上，允许：

- 加粗描边
- 加腮红、笑嘴、眉毛、汗滴、爱心眼
- 微调身体颜色（多角色）
- 轻微 squash & stretch

## 不要做的

- 不要把参考图里的具体地铁构图、分割画面、爱心镜头照搬进《我想 part2》。
- 不要把参考视频里的角色、文字、歌词带进来。
- 不要因为要表情就画成人形或长肢。
- 不要做成 3D、写实、厚涂或复杂光影。

## 一句话

**粗描边、暖色、扁平、简单舞台、表情丰富、多角色换色。** 这是本 MV 的新画风目标；之前的纯像素风只作为历史参考，不再强制。
